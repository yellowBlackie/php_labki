# Практична робота №12

## Анімація, Canvas та інтерактивні елементи

**Варіант 19 — Трекер занять спортом/тренувань**

### Обґрунтування вибору варіанта

У попередніх практичних роботах мій застосунок розроблявся як фітнес-трекер. Тому для цієї роботи було обрано варіант 19, оскільки він напряму відповідає предметній області застосунку та дозволяє використати реальні дані тренувань із попередніх практичних робіт.

За умовою варіанта 19 потрібно реалізувати Canvas-стовпчикову діаграму тривалості тренувань за днями тижня.

## Що реалізовано

Практична робота №12 продовжує функціональність фітнес-трекера з попередніх робіт.

На одній сторінці доступні:

- пошук тренувань за типом;
- таблиця всіх тренувань;
- додавання нового тренування;
- загальна кількість тренувань;
- загальна тривалість;
- сумарно спалені калорії;
- Canvas-діаграма тривалості тренувань за днями тижня;
- визначення найактивнішого дня;
- повторний запуск та зупинка Canvas-анімації;
- підказка при наведенні курсора на стовпчик.

## Джерело даних

Дані не захардкоджені.

Сторінка використовує API з попередньої практичної роботи:

```text
../lab8/api.php?resource=workouts
```

Після успішного отримання масив тренувань також зберігається в `localStorage`.

## Canvas

Для діаграми використано:

```javascript
canvas.getContext('2d');
```

Стовпчики малюються через:

```javascript
ctx.fillRect(...);
```

Перед кожним кадром Canvas очищається:

```javascript
ctx.clearRect(...);
```

Для плавної анімації використовується:

```javascript
requestAnimationFrame(...);
```

Для зупинки:

```javascript
cancelAnimationFrame(...);
```

## Реакція на зміну даних

Після додавання нового тренування:

1. дані відправляються в API;
2. список тренувань завантажується повторно;
3. таблиця оновлюється;
4. статистика перераховується;
5. дані за днями тижня агрегуються повторно;
6. Canvas-графік автоматично запускає нову анімацію.

Таким чином Canvas безпосередньо реагує на реальну зміну даних застосунку.

## Запуск

Apache і MySQL мають бути запущені.

Відкрити:

```text
http://localhost/labki_php/lab12/index.php
```

Також повинна працювати практична №8:

```text
http://localhost/labki_php/lab8/api.php?resource=workouts
```

## Перевірка

1. Відкрити `lab12/index.php`.
2. Переконатися, що таблиця містить тренування.
3. Перевірити пошук за типом.
4. Додати нове тренування через форму.
5. Переконатися, що запис з'явився в таблиці.
6. Переконатися, що статистика змінилася.
7. Переконатися, що Canvas автоматично перебудувався.
8. Навести курсор на стовпчик.
9. Натиснути `Запустити анімацію`.
10. Під час анімації натиснути `Стоп`.

## Висновок

У практичній роботі було інтегровано Canvas API у вже створений фітнес-трекер. Діаграма показує сумарну тривалість тренувань за днями тижня та будується за реальними даними з API. Для анімації використано `requestAnimationFrame`, для очищення кадру — `clearRect`, а для зупинки — `cancelAnimationFrame`. Після додавання нового тренування таблиця, статистика та Canvas-діаграма оновлюються автоматично.
